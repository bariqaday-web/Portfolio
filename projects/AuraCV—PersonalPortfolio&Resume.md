# AuraCV — Personal Portfolio & Resume

Independent light-mode portfolio and resume template for a design systems and lead frontend engineering profile.

## Included

AuraCV uses a clean Notion/Stripe-inspired visual system with a floating navigation bar, profile metrics, high-impact project cards, experience table, skills and tools matrix, recommendations, and a structured contact form.

## Run locally

```bash
python3 -m http.server 4179
```

Open `http://localhost:4179`.

## Customize

Replace the profile, project data, metrics, career rows, social links, and contact copy in `index.html`. Connect the form, CV CTA, and case-study links to your own backend or services. The template is frontend-only and designed for easy customization.
