# AuraConsult — Executive Strategy Advisory Landing Page

A premium, one-page static landing page built with semantic HTML5 and Tailwind CSS utilities.

## Run locally

```bash
python3 -m http.server 3000 --bind 0.0.0.0
```

Then open `http://localhost:3000`.

## Included

- Responsive executive navigation with mobile menu
- Hero conversion section and credibility stats
- Advisory services cards
- Filterable case-study results table
- Methodology and leadership sections
- Strategy audit form with client-side confirmation state
- Route manifest and project logo metadata

The page uses the Tailwind CDN for a portable, no-build export and includes a small inline CSS layer for brand-specific motion and visual treatments.
