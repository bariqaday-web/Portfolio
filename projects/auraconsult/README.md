# AuraConsult — Executive Strategy Advisory

A responsive, single-page consulting landing-page template built with semantic HTML5, Tailwind CSS utilities, a focused custom stylesheet, and small vanilla JavaScript interactions.

## Preview

The site is served as a static page. Run it through any static web server and open `/`.

## Package structure

- `index.html` — complete page structure, metadata, and content
- `assets/styles.css` — responsive visual system and component styling
- `assets/app.js` — mobile navigation, case-study filters, form validation, and preview-only confirmation
- `assets/aura-hero.svg` — local, self-contained visual fallback for the hero
- `assets/aura-mark.svg` — AuraConsult brand mark
- `manus-routes.json` — declared page routes for the managed preview

Tailwind utilities and the requested Inter / Plus Jakarta Sans fonts are loaded from public CDNs. For an offline deployment, compile and host the Tailwind stylesheet and font files locally, then update the links in `index.html`.

## Before publishing or reselling

This is a customizable presentation template, not a verified representation of a real advisory firm. The firm metrics, case study outcomes, company descriptions, advisor biography, credentials, quote, editorial references and testimonial prompts are illustrative placeholders. Replace every sample claim with substantiated, approved information and obtain any required permissions before publication. Confirm AuraConsult brand and domain availability before commercial use.

The Strategy Audit form validates input in the browser but does not transmit or store submissions. Connect it to a secure, consent-aware form endpoint, CRM or booking system before collecting real lead information. Update the privacy notice and applicable legal disclosures for the deployment jurisdiction.

The live managed preview may load an automatically generated hero illustration from project storage; the local SVG fallback is included so the downloadable package remains visually complete on another host.
