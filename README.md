# برق اليوم — Portfolio

معرض أعمال ثابت باللغة العربية باسم استبرق ناجي (برق اليوم). الموقع مبني بدون خادم أو قاعدة بيانات، ويعرض مفاهيم وتجارب تصميمية شخصية.

## إضافة تصميم جديد

1. ضع صورة أو صور المشروع داخل مجلد `assets/`.
2. افتح `app.js` وأضف عنصرًا جديدًا إلى مصفوفة `projects`.
3. استخدم اسمًا وصفيًا وتصنيفًا مناسبًا، ثم أضف طريقة العرض الخاصة بالمشروع عند الحاجة داخل `visualMarkup`.
4. حدّث عداد المشاريع في HTML إذا أصبحت الأعداد مختلفة.

## التشغيل محليًا

لأن الموقع ثابت، يمكن تشغيله بأي خادم ملفات، مثل:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## GitHub Pages

### الطريقة الأسهل

1. أنشئ مستودعًا جديدًا على GitHub، مثل `bariqaday-portfolio`، واجعله Public إذا أردتِ إرسال الرابط للشركات.
2. فكّي ضغط ملف البورتفوليو، ثم ارفعي **محتويات المجلد الداخلية** إلى جذر المستودع، بحيث يكون `index.html` ظاهرًا مباشرة في الصفحة الرئيسية للمستودع.
3. من **Settings → Pages** اختاري `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)` واضغطي Save.
4. بعد اكتمال النشر سيكون الرابط غالبًا بهذا الشكل: `https://bariqaday-web.github.io/bariqaday-portfolio/`.
5. اختبري الرابط من نافذة خاصة قبل إرساله للشركات. ملف `.nojekyll` موجود لتجنب معالجة Jekyll غير المطلوبة.
